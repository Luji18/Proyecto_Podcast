# 🎙️ Proyecto Podcast – Arquitectura de Software

## Microservicios vs Arquitectura Monolítica

Este repositorio fue creado para almacenar los materiales correspondientes a nuestro proyecto de podcast académico sobre **Arquitectura de Software**.

En el podcast desarrollamos el tema **“Microservicios vs Arquitectura Monolítica”**, explicando sus principales características, diferencias, ventajas y desventajas.

## Integrantes

- Luján Marecos.
- Marcos Dominguez.
- Luz Marecos.

## Objetivo

El objetivo de este podcast es comprender las diferencias entre una arquitectura monolítica y una arquitectura basada en microservicios, analizando de forma sencilla cómo funcionan y en qué situaciones pueden utilizarse.
